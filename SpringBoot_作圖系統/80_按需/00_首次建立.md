# 按需：首次建立

只在`00_先讀_狀態與啟動.md`顯示`未建立`，且使用者要求正式建立時執行。

## 第一階段：只讀理解

1. 讀`01_通用作圖流程.md`至`03_格式與狀態定義.md`。
2. 檢查使用者提供的來源、既有成果、樣板、規格及實際資料夾。
   - 第一階段只讀分析不接手。若同一工作存在交接系統，使用者確認正式建立後，在第二階段第一次寫入前依`70_交接系統協作.md`自動執行交接前置檢查並取得工作權。
3. 區分：
   - 已確認事實與規則。
   - 目前成果的實際狀態。
   - AI建議。
   - 尚需使用者決定。
4. 先辨識正式部署位置：作圖系統、圖片成果根目錄、可選交接系統及其他工作資料。預設作圖系統與`picture`同層，不把舊容器名稱當成永久架構。
5. 先向使用者回報預計填入的工作目的、位置、規則、候選方案、導入資料處置與缺少資訊。
6. 未獲確認前，不移動成果、不重寫既有規格、不宣布樣板已確認。

## 第二階段：正式建立

使用者確認後：

1. 將系統狀態改為`建立中`。
2. 建立唯一工作代號。
3. 填寫`10_本工作做圖說明.md`。
4. 將工作SOP、品牌指南及其他規格來源登錄至`13_工作規格與來源.md`：
   - 由本系統管理的原文放`40_工作規格`。
   - 由其他位置負責的原文保持原位，只建立引用。
5. 將仍有效的長期規則整理至`11_本工作視覺規格.md`；工作專用規則不得寫回通用文件。
6. 將目前圖片、批次、過期情報及下一步整理至`12_當前圖片與批次.md`。
7. 只將使用者明確確認的樣板／元件登錄至`20_樣板與元件登錄.md`。
8. 候選方法登錄至`21_候選方案登錄.md`，並依`10_候選方案與樣板確認.md`測試，不假裝已確認。
9. 將工作專用製作方法、驗證器、回歸案例與已知問題解法放`50_工作方法`，並在`22_驗證方法登錄.md`寫清楚能力與限制。
10. 由`02`、現行`11`、`40`、`50`及已登錄外部規格建立`23_規則與回歸索引.tsv`；索引只保存定位資訊，不複製規則全文。
11. 若有歷史QA，只保留必要索引；不逐筆搬入活動紀錄，也不從歷史失敗自動建立未結案修正。
12. 執行首次一致性檢查：
   - 路徑存在或明寫尚未建立。
   - 版本與狀態一致。
   - 候選與正式方案分開。
   - QA通過與使用者確認分開。
   - 使用者入口與內部資料分開。
   - `00`不含視覺規格、當前任務、批次或樣板的易變鏡像。
   - 關鍵QA能指出生產證據、驗證證據與獨立性；不能時保持未驗證。
   - 臨時導入資料已標示吸收、引用、取代或待處理，不是日常必讀入口。
   - `23`可追溯到正式規則來源，且未被當成規則權威。
13. 完成後將系統狀態改為`可使用`，並依實際進度更新`12`；依manifest、`00`與`12`產生`module_status.json`。
14. 若有交接系統，依`70_交接系統協作.md`同步最小里程碑與入口。

任何關鍵步驟中斷時保持`建立中`或改為`暫停待處理`，不得假裝完成。

## 從既有做圖資料導入

將舊資料分為：

- 通用流程：只在本系統尚未涵蓋且確實通用時提出修正，不直接複製。
- 工作權威規格：先登錄到`13`；由本系統管理者放`40`，外部管理者保留原文引用與版本。
- 工作專用現行規則：將執行所需的最短摘要整理到`11`，並標明來源ID。
- 工作專用方法：放`50`並登錄至`22`，不得因曾經使用過就宣稱可獨立驗證。
- 規則與回歸索引：由現行來源重建，不沿用舊索引的判斷。
- 候選方法：整理成候選ID。
- 已確認樣板：核對確認範圍後登錄至`20`。
- 歷史與已淘汰方法：保留原處或索引至`90_內部歷史`，不得混入現行規則。
- QA紀錄：保留可追溯位置，不將全部歷史當成必讀內容。

舊資料保持原樣；除非使用者明確要求，不因導入而刪除、搬移或封存。

導入不是把舊資料夾改名或整份貼入本系統。來源仍由原文件負責時，`13`保存其位置、版本、權威程度與同步狀態；`11`只保存AI每次作圖必須快速取得的執行摘要。

## 取代舊容器或臨時導入資料

需要改成正式同層部署時，先分類：

1. 通用系統核心 → 新`作圖系統`。
2. 工作專用規格 → `40_工作規格`或外部引用。
3. 工作專用方法與驗證 → `50_工作方法`及`22`。
4. 圖片素材與成果 → 使用者確認的`picture`或其他成果根目錄。
5. 臨時導入說明 → 吸收、引用或標示已取代，不作正式入口。
6. 歷史與舊控制入口 → 保留原處並標示已取代；確認新版可用前不刪除。

轉換後更新所有現役路徑，確認只有一個正式作圖系統與一個正式成果根目錄。歷史文字中的舊路徑保持原文，不算現役殘留。
