# 回饋與問題待交付

這個資料夾集中存放要交給制度維護者的填好報告。它不是工作規則、當前進度、交接日誌或知識庫。

- 使用`！填問卷`建立 AI 使用回饋。
- 使用`！問題回報`建立具體問題報告。
- 使用者可開啟`../80_按需/60_回饋與問題/使用者回饋表單.html`，按「提交並保存」並選擇交接資料夾或本資料夾；支援的瀏覽器會直接在這裡建立 Markdown。
- 瀏覽器不支援直接保存時，表單才會改為下載；此時需把下載檔放到這裡。
- 需要分享時，直接提供本資料夾即可。

正常接手、交接、版本升級與一致性檢查不讀取本資料夾內容，也不把歷史報告當成現況。制度升級時整個資料夾原樣保留。

請勿放入密碼、Token、Cookie、私密金鑰或不必要的個人資料。
