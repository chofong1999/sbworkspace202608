# Homework03 RPG 原版畫面參考

本資料夾保存 Homework03 桌面版 RPG 的實際畫面，供 GamePlatform Web 移植、檢查與後續交接使用。

## 使用原則

- 以 Homework03 的 UI 程式碼、資料內容與本資料夾截圖共同作為原版依據。
- 角色、職業、技能、裝備、道具、敵人、關卡、數值與操作流程應盡量忠實保留。
- 只因 Web 平台、既有 JWT 登入、瀏覽器操作及響應式版面而做必要調整。
- 截圖呈現的視窗形式不是不可變的限制；應優先保留操作層級、返回位置及使用者狀態。
- 原版以子視窗覆蓋地圖或戰鬥畫面。Web 可採對話框、側邊面板，或能保留原頁狀態的獨立畫面；關閉後仍須回到原操作位置。
- Homework03 的管理員資料維護、技能建構器與測試工具目前不屬於移植範圍。

## 畫面索引

1. `01-character-roster.png`：角色名冊、角色概覽、建立角色與進入遊戲入口。
2. `02-character-create.png`：角色命名、六職業、職業屬性、成長、特性及可學技能。
3. `03-adventure-map.png`：出征角色摘要、六項功能入口、四地區與關卡狀態。
4. `04-stage-preparation.png`：關卡資訊、敵人、掉落物、攜帶技能及出征確認。
5. `05-skill-configuration.png`：已學技能、已攜帶技能、技能詳細資訊及配置操作。
6. `06-character-status.png`：完整能力值、職業特性、裝備特性與當前狀態。
7. `07-inventory.png`：消耗品、技能卷軸、素材、任務道具及道具詳細資訊。
8. `08-shop.png`：購買、出售、買回、金幣、素材條件及商品資訊。
9. `09-equipment.png`：目前穿戴、裝備背包、職業篩選及裝備詳細資訊。
10. `10-battle.png`：雙方戰鬥資訊、技能、技能說明、戰鬥紀錄與操作區。
11. `11-victory-result.png`：勝利結算、經驗值、金幣、掉落物與再次挑戰。
12. `12-enemy-status.png`：敵方能力值、獎勵、種族特性、個體特性及當前狀態。

## 交接注意事項

- 截圖是特定角色與進度的實例，不應把畫面中的即時數值硬編碼成固定資料。
- 若截圖與程式碼呈現不同狀態，以 Homework03 實際資料與 UI 邏輯判斷動態行為。
- 若 Web 版必須偏離原版流程或資料，應先記錄差異並與負責人討論。
