## 新檢查發現

- 正式 Poker 直接加入 UI 與 JWT／modeId／Lobby Room 後端契約不相容。
- Poker／Tjpoker 所有房間共用 Service 的 `synchronized` 全域鎖。
- GameDataInitializer 不更新既有設定；GameMode 缺少 `(gameId, modeCode)` DB unique constraint。
- 刪除 Game／Mode 可能讓沒有外鍵的 Lobby Room／Board TeamPost 留下失效 ID。
- Board 傳 Member.id 給 Poker，而正常 Lobby Poker 使用 platform User ID；Board 權限檢查也信任 request 提供的 ID。
- Quiz 可只交一題或重複題目取得 100 分，沒有伺服器考卷／倒數 session，排行榜 username 由 request 指定。
- Quiz 考卷 JSON 直接包含 `isCorrect`，交卷前即可看到正解。
- Quiz 題庫異動公開，未清理富文字即保存並插入 `innerHTML`。
- Lobby 允許前端人數覆蓋 GameMode 上限，更新房間也未核對 mode／min／max。
- Board 四個 entity 使用 Hibernate 已標記淘汰的 `GenericGenerator`。
- 各前端分散固定使用 `http://<hostname>:8080`；Vite production build 仍未包含實際多頁畫面。
