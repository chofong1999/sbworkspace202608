## 目標與完成條件

在團隊共用的簡易遊戲平台中完成遊戲資料系統、獨立田忌撲克及正式房間系統。田忌撲克保留舊版玩法，Java／Spring Boot 後端掌握核心規則；Game／GameMode 提供遊戲目錄、模式、人數與入口資料；房間系統依遊戲資料建立房間、管理玩家與開始對局，最後由平台以 iframe 載入獨立遊戲。

## 範圍

- 包含：Game／GameMode 遊戲資料系統、田忌撲克遊戲核心與獨立介接、正式共用房間系統、測試用 Poker 房間、REST、WebSocket、iframe 入口及遊戲結果。

## 目前有效的決定與限制

- 遊戲固定入口為 `http://<遊戲主機>:8080/poker_client.html`；目前區域網路測試主機為 `10.10.1.213`，前端 API 使用相對路徑，不寫死 IP。
- 正式房間系統由平台獨立負責；目前遊戲內只保留測試所需的座位與對局連線管理。
- 製作順序固定為遊戲管理系統、獨立 Poker、正式房間系統、最後串接；目前先完成遊戲管理系統，暫不繼續房間傳值串接。
- Poker 是一筆 Game；對戰電腦與玩家對戰是兩筆 GameMode；GameMode 的 minPlayers／maxPlayers 代表真人玩家數。
- Game 資料預先建立，同時預留 Admin 後台管理；遊戲與後端入口只保存相對路徑。
- 所有模式都經過建立房間流程；房間結束後刪除；第一版不加入觀戰者。
- 正式平台一個房間只進行一局 Poker；遊戲結束回到平台大廳，再玩一局必須建立新房間，不沿用同一 roomId 重新發牌。
- 雙人正式流程以舊專案 `referenceui.ReferenceGameUI` 為依據：每輪分別選 3／5／5 張，雙方確認後才公開該輪結果，再進下一輪。
- 測試版資料保存在伺服器記憶體；Spring Boot 重啟後房間與進行中對局消失。
- 玩家離開只釋放座位，不結束或重置對局；補位者接手該座位既有進度。
