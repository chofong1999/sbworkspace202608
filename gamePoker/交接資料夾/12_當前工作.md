## 已完成並確認

- Poker 的 WebSocket 中斷不再直接執行 `leave()`；玩家主動離開由 Poker 的 DELETE leave API 處理。
- Poker 中途離開會呼叫 `RoomLifecycleService.finishRoom(..., ABANDONED)`；三輪正常結束會呼叫 `finishRoom(..., NORMAL)`。
- Room lifecycle 會發布 `RoomFinishedEvent`，實際房間頻道由 `RoomWebSocketHandler.closeRoomChannel()` 發出 `ROOM_FINISHED` 並清理連線。
- 遊戲開始後，等待區會請外層 `chatclient` 接手房間 WebSocket；因此 iframe 進入 Poker 後仍保有房間聊天連線。
- 外層 Chat 已能透過接手的 WebSocket 發送房間訊息；收到 `ROOM_FINISHED` 後顯示系統訊息並禁止繼續輸入。
- 最新版本已恢復開始遊戲 API 的成功／失敗提示。
- `main c8b3b76` 上 Poker、Tjpoker、Chat JavaScript 語法檢查通過，後端 Maven compile 通過。
