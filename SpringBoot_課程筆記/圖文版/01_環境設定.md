# Spring Boot 圖文學習筆記 01：環境設定

[返回總目錄](../README.md)｜[純文字版](../純文字版/01_環境設定.md)

- 使用環境：Eclipse IDE、JDK 21、Apache Tomcat 10.1、Spring Tools
- 完成目標：Eclipse使用JDK 21，Tomcat Runtime指向JDK 21，並能在新建精靈中看到`Spring Boot → Spring Starter Project`

> 圖中的軟體小版本可能與目前下載版本不同。判斷時以JDK主版本21、Tomcat 10.1及新版Spring Tools為準。

## 0. 開始前準備

- 已安裝並能開啟Eclipse IDE。
- 已安裝完整JDK 21，例如`C:\Program Files\Java\jdk-21.0.10`。
- 已下載並解壓縮Tomcat 10.1，例如`C:\apache-tomcat-10.1.25`。
- 電腦可以連線至Eclipse Marketplace。

## 1. 開啟XML外部資源下載與標籤自動閉合

進入：

```text
Window → Preferences → XML (Wild Web Developer)
```

請勾選：

- `Download external resources like referenced DTD, XSD`
- `Enable autoclosing of XML tags`

![Eclipse XML設定頁面](../圖文版素材_待製作/images/01_XML設定.png)

*圖1：XML設定位置。畫面中的第一個選項尚未勾選；實際完成設定時，兩個選項都應勾選。*

完成後按`Apply and Close`。

## 2. 將Eclipse預設Java改為JDK 21

進入：

```text
Window → Preferences → Java → Installed JREs
```

調整前可能同時看到JDK 21與Eclipse原本的預設JRE，而且勾選的仍是原預設項目：

![Installed JREs調整前](../圖文版素材_待製作/images/02_JRE調整前.png)

*圖2：調整前，JDK 21已經存在，但尚未成為預設；另一個JRE仍被勾選。*

依序完成：

1. 確認JDK 21已在清單中；若沒有，按`Add`或`Search`加入。
2. JDK位置可使用`C:\Program Files\Java\jdk-21.0.10`。
3. 勾選JDK 21，使它成為預設Java執行環境。
4. 選取不再使用的Eclipse預設JRE，按`Remove`。
5. 按`Apply and Close`。

完成畫面應只保留並勾選JDK 21：

![JDK 21設定完成](../圖文版素材_待製作/images/03_JDK21設定完成.png)

*圖3：完成後，JDK 21是清單中唯一且已勾選的Java執行環境。*

> `Remove`只會移除Eclipse中的JRE設定，不是刪除電腦上的JDK資料夾。Spring Boot開發需要完整JDK，不應改用只有執行功能的JRE。

## 3. 調整程式編輯器字體

進入：

```text
Window → Preferences
→ General → Appearance → Colors and Fonts
→ Basic → Text Font → Edit
```

範例設定：

- 字型：`Consolas`
- 樣式：標準
- 大小：`12`

![Eclipse字體設定](../圖文版素材_待製作/images/04_字體設定.png)

*圖4：選取Text Font後開啟Windows字型視窗，設定Consolas、標準、12。*

先按字型視窗的「確定」，再回Preferences按`Apply and Close`。

## 4. 建立Apache Tomcat 10.1 Runtime

進入：

```text
Window → Preferences → Server → Runtime Environments
```

依序完成：

1. 按`Add`。
2. 選擇`Apache Tomcat v10.1`。
3. 在`Tomcat installation directory`指定Tomcat解壓縮目錄，例如`C:\apache-tomcat-10.1.25`。
4. `JRE`選擇`jdk-21.0.10`。
5. 按`Finish`，最後按`Apply and Close`。

![Tomcat 10.1 Runtime設定](../圖文版素材_待製作/images/05_Tomcat設定.png)

*圖5：左側是Runtime清單；右側指定Tomcat安裝目錄及JDK 21。*

若電腦尚未準備Tomcat，可使用`Download and Install`；若已自行下載並解壓縮，使用`Browse`指定該資料夾即可。

## 5. 從Eclipse Marketplace安裝Spring Tools

開啟商店：

```text
Help → Eclipse Marketplace...
```

![Eclipse Marketplace入口](../圖文版素材_待製作/images/06_Eclipse商店入口.png)

*圖6：由Help選單進入Eclipse Marketplace。*

在搜尋欄輸入`spring boot`，選擇上方的`Spring Tools (aka Spring Tool Suite)`並按`Install`：

![搜尋並安裝Spring Tools](../圖文版素材_待製作/images/07_安裝SpringTools.png)

*圖7：應安裝新版Spring Tools；畫面中的版本號可能隨Marketplace更新。不要選擇已停止維護的Spring Tools 3 Add-On。*

接著接受授權條款並繼續。安裝期間可從Eclipse右下角查看進度：

![Spring Tools安裝進度](../圖文版素材_待製作/images/08_安裝進度.png)

*圖8：安裝尚未完成時會顯示Installing Software及百分比。此時先等待，不要立即檢查新建精靈。*

安裝完成後，如果Eclipse要求重新啟動，請重新啟動。

## 6. 確認Spring Tools安裝成功

重新啟動Eclipse後，進入：

```text
File → New → Other...
```

![New Other入口](../圖文版素材_待製作/images/09_NewOther入口.png)

*圖9：由File選單開啟完整的新建精靈清單。*

在`New`視窗中展開`Spring Boot`，應能看到：

- `Import Spring Getting Started Content`
- `Spring Starter Project`

![Spring Boot新建精靈](../圖文版素材_待製作/images/10_STS安裝確認.png)

*圖10：出現Spring Boot分類及Spring Starter Project，表示Spring Tools已安裝成功。*

若找不到：

1. 在上方搜尋欄輸入`spring`。
2. 確認右下角安裝進度已完成。
3. 重新啟動Eclipse後再次檢查。
4. 回到Marketplace的`Installed`分頁，確認Spring Tools確實已安裝。
